01 / PDF 瀏覽

PDF 瀏覽與備註

瀏覽多頁 PDF,可拖曳畫重點或點擊加文字備註,完成後存成新 PDF · 純前端運算,不會上傳。備註是畫在頁面上的圖層,不是 Acrobat 那種可收合的官方留言註解
拖曳 PDF 到這裡開始瀏覽
02 / PDF → IMG

PDF 每頁轉圖片

輸出圖片格式可選 PNG 或 JPG,多頁自動打包成 ZIP
拖曳 PDF 到這裡,或點擊選擇檔案
附註:解析度倍率控制圖片清晰度,倍率 1 約為螢幕等級(檔案小、可能較模糊),2(預設)約為印刷等級,3-4 適合需要放大看細節的用途,6-8 為極高解析度、檔案會非常大且轉換明顯變慢,大型 PDF 不建議用這麼高。輸出格式方面,PNG 無失真、檔案較大,適合需要清晰邊緣或後續編輯的圖片;JPG 為壓縮格式、檔案較小,適合單純瀏覽或分享用途。

09 / PDF UNLOCK

解除 PDF 保護

另存未加密的副本，保留文字、向量與頁面。無開啟密碼的權限保護檔可直接處理；有開啟密碼則需輸入正確密碼。文件與密碼不上傳。
拖曳 PDF 到這裡，或點擊選擇檔案
原檔不會被修改；重新儲存會使原數位簽章失效。首次使用需下載引擎。限 50 MB，支援標準 PDF 密碼加密，不支援憑證或 DRM 保護。
10 / PDF → DOCX

PDF 轉 Word

文字版在瀏覽器擷取可選取文字，保留分頁，不還原原排版、表格與圖片。保留排版模式使用後端；掃描或輪廓文字請使用下方 OCR。
拖曳 PDF 到這裡
11 / FREE OCR → DOCX

免費 OCR → Word

辨識中英文掃描檔、圖片文字或已轉成輪廓的字形，輸出可編輯 Word。全程在您的瀏覽器處理，文件不上傳、不使用 AI token。保留分頁，表格與原始排版不保證還原，下載後請校對。
拖曳 PDF 到這裡，或點擊選擇檔案
首次使用所選語言需下載辨識資料 · 中英混合使用時間通常較長
12 / PDF → XLSX

PDF 轉 Excel

在瀏覽器依文字位置整理列與欄，每頁一個工作表，文件不上傳。複雜表格、合併儲存格與多欄排版需校對；掃描圖片或輪廓文字不含 OCR。
拖曳 PDF 到這裡
13 / PDF → SVG

PDF 轉向量圖

在瀏覽器輸出 SVG，文件不上傳；留空頁碼則全部打包 ZIP。保留原有向量與文字，內嵌圖片仍是圖片；特殊 PDF 效果可能有差異，請檢查輸出。
拖曳 PDF 到這裡
14 / PDF ↓ SIZE

PDF 壓縮

無損整理在瀏覽器重新壓縮 PDF 結構，保留文字、向量與圖片畫質，不保證檔案變小。若需降低圖片解析度，可選後端壓縮（檔案會上傳）。重新儲存可能影響數位簽章。
拖曳 PDF 到這裡
15 / IMG ⤢

圖片放大

放大圖片,可選「平滑」或「銳利」模式,不同內容類型效果不同 · 純前端運算,不會上傳。注意:這是傳統演算法放大,不是 AI 補細節,原本沒有的畫面資訊沒辦法真的補出來
拖曳圖片到這裡,或點擊選擇檔案
附註:「平滑」用瀏覽器內建的高品質縮放演算法,適合相片,但截圖或文字放大後邊緣會變模糊(這是演算法的設計目的,不是bug)。「銳利」不做平滑處理,直接放大像素,邊緣保持銳利不糊,適合截圖/文字/UI畫面,代價是放大倍率高時會看起來有顆粒感、不夠細緻。兩種都不是 AI 補細節,原本沒有的畫面資訊沒辦法真的補出來。
