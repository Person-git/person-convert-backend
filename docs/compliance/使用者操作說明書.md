## 1. 開始使用與資料選擇

1. 開啟公司提供的轉檔平台網址；本平台沒有內建登入／角色登入頁。不要因此認為任何機密文件都已獲准上傳。
2. 依任務選工具。畫面標示「本機處理」時，文件在瀏覽器運算；「後端／上傳」選項會傳送到Render，須先符合公司資料規範。
3. 先複製或保留原檔，選檔／拖入後設定頁碼與選項。常用格式如`1,3,5-7`；空白通常為全部，以功能標示為準。錯誤頁碼應修正，不以改副檔名代替轉檔。
4. 執行時查看進度／經過時間，可按取消；某些步驟須完成後才停止，百分比不是剩餘時間保證。不要同時重複按。

## 3. PDF密碼與保護（09）

只處理自己有權使用的文件。選PDF後使用加密／更換密碼，填兩次新密碼；已有開啟密碼可展開填原密碼。新密碼至少8個字元且UTF-8不超127bytes，中文單字可能占多bytes。

設定操作權限時勾允許的列印／複製／編輯等項目，填獨立管理密碼；可不設開啟密碼而只限制操作。權限限制由閱讀器遵守，部分軟體可忽略，不能阻止截圖。不要把密碼記在測試文件或支援截圖裡。

解除保護分頁可用已知開啟密碼另存副本；無開啟密碼的權限保護檔可嘗試依授權處理。未知開啟密碼、憑證及DRM不屬支援範圍。請自行保存密碼，平台不提供密碼找回。重新儲存可能讓原數位簽章失效。

## 4. PDF轉Word與OCR（10）

1. 選檔後維持「自動判斷（本機）」；文字層不足／亂碼會建議OCR。需要時可手動選文字擷取或OCR。
2. 中文頁尾／中英混合選繁體中文＋英文或簡體中文＋英文；單選英文可能誤認中文。
3. 快速文字偏重可編輯段落及分頁；保留外觀是實驗版，盡量還原位置／顏色／圖片／字型，部分內容仍是不可編輯原圖。
4. 可指定頁碼，先試轉一頁、下載Word實際查看，再轉整份。HTML示意不是Word渲染器。
5. 完成後看校對清單的低信心／保留原圖／可能擁擠提示，可在原頁定位或下載TXT。紅框是來源字框，不是已證明Word疊字。
6. 核對數值、單位、專有名詞、粗斜體、圖片、表格、換行與頁尾。機密或關鍵文件不得未覆核直接外發。
7. 進階後端排版只適合有文字層且允許上傳的PDF，不含OCR，不會因自動判斷而自動上傳。

## 5. Excel及向量（11、12）

Excel依原PDF文字位置分列欄；可先預覽指定範圍首個頁面，掃描頁不含OCR。檢查數值、儲存格及閱讀順序，不以表格看起來整齊作為正確判定。

功能12的PDF→SVG可選頁碼，單頁SVG或多頁ZIP。SVG→PDF則選SVG，含中文／特殊文字時上傳有權使用且涵蓋文字的TTF，或先將文字轉外框。字型限20MiB，不支援TTC／OTF；所選字型統一為一般樣式。SVG5MiB上限，濾鏡／遮罩／腳本／外部連結等不支援會明示。線條／形狀保留向量，原照片仍是點陣圖，不會自動描圖。檢查放大後輪廓、字型及背景，搜尋／複製結果可能因閱讀器而不同。

## 6. 再次下載、隱私與離線

完成會嘗試自動下載；若未取得檔案，可在該功能「上次完成的檔案」按再次下載，不會重跑運算。只是變更選項尚未再執行，按鈕仍下載上次結果。結果只在目前分頁；重選／移除、下一次輸出、重新整理、離開／關閉或瀏覽器回收即失效。正式結果總額256MiB、單份128MiB，超額會釋放較早結果，沒有固定保留分鐘數。

已下載磁碟檔不會被網站一起刪除；確認公司允許的保存／分享位置。安裝App是自願操作，不會自動安裝或開機執行。離線前需先連線下載引擎及語言並試轉；後端模式必須連網。清站台資料可能同時清偏好及離線資源，請先下載結果。

## 7. 常見錯誤與求助

| 情況 | 可採取的步驟 |
| --- | --- |
| 無文字／亂碼 | Word用本機OCR及正確語言；Excel無OCR，改從有文字來源取得表格 |
| 轉換慢／記憶體錯誤 | 減少頁數、先試一頁、降低圖片倍率、關閉其他大型工作；不要無限重試 |
| 後端逾時／忙碌 | 等待後重試或選本機模式；確認檔案小於25MiB，避免未授權上傳 |
| 加密或損壞 | 輸入正確開啟密碼或另存完整未加密副本；不能靠改檔名解密 |
| SVG缺字／外部資源 | 提供相符TTF，或來源軟體轉外框／內嵌PNG/JPG／簡化效果 |
| 找不到下載 | 查看瀏覽器下載紀錄與再次下載按鈕；重載後無歷史結果，只能重轉 |

支援窗口由公司指定。通報工具編號、模式、頁數、檔案大小、瀏覽器版本、錯誤訊息與時間；先遮去密碼、個資與文件內容。不得為方便診斷直接把機密原檔寄給他人或上傳公開服務。操作說明需由一般使用者覆核後核准。
