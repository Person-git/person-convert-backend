# Word 固定回歸檢查

測試內容均為公開合成資料，不包含使用者的機密 IFU 或其他原檔。

1. 執行 `node tests/test_word_regression.cjs` 及全部 `tests/test_*.cjs`。固定 JSON 的期望座標／粗斜體／CJK 字型／圖片關係與原圖交界不能隨實作輸出自動更新；期望值變更須說明原因。
2. `fixtures/word-regression-sample.pdf` 是保存的公開固定輸入。`word-regression.html` 是產生來源，透過工作區 HTTP 伺服器開啟；只有刻意改版樣本時才重新產生 PDF，須一併檢查兩頁內容。產生器使用瀏覽器字型，跨電腦重新產生可能不同。
3. 修改轉換演算法時，在本機平台分別跑自動、強制 OCR、快速文字／保留外觀，以及單頁試轉、指定第 2 頁。檢查語言選擇、取消與重選後校對清單是否清除。
4. 在 Word 實際查看兩頁：原生／掃描中英文、一般／粗體／斜體／粗斜體、圖片、頁尾及原圖文字交界，不可只憑 HTML 示意或 XML 測試宣稱視覺正確。不得自動啟用編輯或繞過受保護檢視。
5. 校對清單須包含高信心但保留原圖的內容，篩選三類、TXT、無符合項目與 200 項上限均正常；來源字框擁擠是幾何提示，不能宣稱偵測到 Word 實際重疊。

6. 驗證完成後隔一段時間仍可「再次下載」，下載內容相同且不重做轉換；Word 與校對 TXT 各自保留。重新選檔／移除／下一次輸出清除該功能舊結果，其他功能仍保留；重新整理後全部結果消失。選檔後立即輸出，背景預覽稍後完成不得誤清除新結果。
7. 驗證 PDF、ZIP、Excel、SVG、圖片等共用下載流程，以及 `node tests/test_download_results.cjs` 的替換、所屬功能隔離、128 MiB 單檔限制、256 MiB 總額釋放與 URL 清除檢查。只改選項時下載仍為上一次完成結果；Excel／壓縮抽查不清除正式結果。
8. 校對項目「在原頁定位」應顯示正確來源頁及紅框，關閉／重選取消舊繪製；不是 Word 渲染預覽。重新開啟只記住 OCR 語言與快速文字／保留外觀，不記住文件、密碼或後端模式，恢復預設偏好須有效。

自動檢查鎖定結構與位置，不是像素級 Word 排版保證；OCR 文字與分數在不同引擎／字型環境可能有差異。機密文件只作本機人工驗收，不加入版本庫、公開樣本或部署 ZIP。
